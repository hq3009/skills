# AI Skills

This repository is used to collect and manage AI Skills. The goal is to organize reusable AI capabilities, task templates, workflow ideas, and reference materials into a consistent skill structure so they can be reused and extended across scenarios.

## Project Purpose

This repository is suitable for:

- Collecting various AI-focused skills
- Standardizing skill descriptions, templates, and reference materials
- Building reusable task workflows
- Maintaining a unified structure for future skill expansion

## Directory Structure

```text
skills/
├── README.md
├── skill-name-1/
│   ├── SKILL.md
│   ├── assets/
│   ├── references/
│   └── scripts/
├── skill-name-2/
│   ├── SKILL.md
│   ├── assets/
│   ├── references/
│   └── scripts/
└── ...
```

## Typical Structure of Each Skill

Each skill directory usually contains:

- `SKILL.md`: skill description covering the use case, objective, and usage guidance
- `assets/`: templates, examples, and reusable content
- `references/`: reference materials, patterns, standards, and examples
- `scripts/`: optional helper scripts or processing logic

## How to Use It

1. Open the relevant skill directory.
2. Read the `SKILL.md` file in that directory.
3. Select the matching template or reference material based on the task scenario.
4. Use the skill to generate content, process data, or complete the task.

## Maintenance Principles

- Each skill should correspond to a clear use case.
- The README serves as a high-level overview and does not need to detail every individual skill.
- When adding a new skill, keep naming, structure, and folder conventions consistent.
- Templates and reference materials should remain as general and reusable as possible.

## Note

This repository is not centered on a single skill; instead, it provides a unified framework for collecting and managing AI Skills. As new task-oriented capabilities are added, they can all follow the same structure and grow into a sustainable, expandable knowledge base.

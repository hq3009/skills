# 党政机关公文格式规范（`--mode official`）

依据 GB/T 9704-2012《党政机关公文格式》，脚本已固化的取值如下。

## 1. 页面设置

| 项目           | 取值               | 说明                     |
| :------------- | :----------------- | :----------------------- |
| 纸张           | A4 210 mm × 297 mm |                          |
| 版心           | 156 mm × 225 mm    | 由页边距推算得出         |
| 上白边（天头） | 37 mm ± 1 mm       |                          |
| 下白边（地脚） | 35 mm              | 297 − 37 − 35 = 225 mm ✔ |
| 左白边（订口） | 28 mm ± 1 mm       | 210 − 28 − 26 = 156 mm ✔ |
| 右白边（翻口） | 26 mm              |                          |
| 页眉距边界     | 25 mm              |                          |
| 页脚距边界     | 25 mm              | 页码排在版心下边缘之下   |
| 装订线         | 0 cm               |                          |

> 版心宽度校验：210 − 28 − 26 = 156 mm；版心高度校验：297 − 37 − 35 = 225 mm。
> 改页边距请修改 `scripts/md2docx.py` 中的 `PageSpec`。

## 2. 字体与字号

| 要素                           | 中文字体                  | 西文字体        | 字号         | 加粗       |
| :----------------------------- | :------------------------ | :-------------- | :----------- | :--------- |
| 文件标题（md `#`，docx Title） | 方正小标宋简体            | Times New Roman | 二号 22 pt   | 否         |
| 正文                           | 仿宋（可选 仿宋\_GB2312） | Times New Roman | 三号 16 pt   | 否         |
| 一级标题（docx Heading 1）     | 黑体                      | Times New Roman | 三号 16 pt   | 否         |
| 二级标题（docx Heading 2）     | 楷体                      | Times New Roman | 三号 16 pt   | **是**     |
| 三级标题（docx Heading 3）     | 仿宋                      | Times New Roman | 三号 16 pt   | **是**     |
| 四级标题（docx Heading 4）     | 仿宋                      | Times New Roman | 三号 16 pt   | 是         |
| 五级标题（docx Heading 5）     | 仿宋                      | Times New Roman | 三号 16 pt   | 否         |
| 表格正文                       | 宋体                      | Times New Roman | 五号 10.5 pt | 表头行加粗 |
| 表格标题（表题）               | 黑体                      | Times New Roman | 四号 14 pt   | 否         |
| 图片标题（图题）               | 黑体                      | Times New Roman | 四号 14 pt   | 否         |
| 注释／附注（引用块）           | 仿宋                      | Times New Roman | 三号 16 pt   | 否         |
| 页码                           | 宋体                      | Times New Roman | 四号 14 pt   | 否         |

**所有文字颜色一律为黑色**（含超链接），脚本对每一个 run 显式写入 `w:color 000000`。

> 字体缺失处理：本机未装「方正小标宋简体」时，Word/WPS 会自动替换。
> 可用 `--title-font` 改为「华文中宋」「黑体」等已装字体；
> 正文可用 `--prefer-fangsong-gb2312` 切换为「仿宋\_GB2312」。

## 3. 段落格式

| 项目         | 取值                                                                    |
| :----------- | :---------------------------------------------------------------------- |
| 正文对齐     | 两端对齐                                                                |
| 正文首行缩进 | 2 个字符（`w:firstLineChars="200"`）                                    |
| 正文行距     | 固定值 28.8 磅（225 mm ÷ 22 行 ≈ 28.99 磅，取 28.8 保证满版正好 22 行） |
| 段前/段后    | 0 磅                                                                    |
| 各级标题缩进 | 首行缩进 2 字符，与正文一致                                             |
| 注释/附注    | 左缩进 2 字符，不首行缩进                                               |
| 列表项       | 悬挂缩进 2 字符，每深一级左侧再缩进 2 字符                              |
| 表格         | 整体居中；表题居中置于**表上方**；单元格垂直居中；表头行跨页重复        |

行距可用 `--line-spacing` 覆盖，例如 `--line-spacing 30`。

## 4. 页码

- 用 4 号半角宋体阿拉伯数字。
- 数字左右各放一条一字线：`－ 1 －`。
- **单页码居右空一字，双页码居左空一字**（启用 `w:evenAndOddHeaders`，分别写入 `default`(奇数页) 与 `even`(偶数页) 两个页脚部件）。
- 不需要奇偶区分时用 `--no-odd-even`，页码统一居中。
- 完全不要页码用 `--no-page-number`。

## 5. 明确不做的内容

按照用户约定，**不生成**：

- 版头部分：发文机关标志（红头）、发文字号、签发人、红色分隔线
- 文末版记：抄送机关、印发机关、印发日期、版记中的分隔线
- 任何封面页

只输出「标题 + 正文版式 + 页码」这一版心内的内容。

## 6. 结构层次序数

GB/T 9704 推荐的顺序是：

```
一、   （一级标题）
（一） （二级标题）
1.    （三级标题）
（1）  （四级标题）
```

建议直接写在 markdown 标题文字里（`## 一、评估范围`）；
也可不加，改用 `--auto-number` 由脚本自动生成。
